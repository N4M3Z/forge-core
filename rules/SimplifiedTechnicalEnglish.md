Write all prose in Simplified Technical English (ASD-STE100). This applies to replies, documents, commit messages, MR descriptions, code comments, and skill text.

Use short sentences: up to 20 words for an instruction, up to 25 for a description. Use the active voice. Give one instruction per sentence. Use one word for one meaning. Do not use idioms. Do not stack more than three nouns. Keep facts, commands, tables, and code unchanged.
